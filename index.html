Apresentação

Hoje vamos realizar uma experiência importante para compreender como os computadores se comunicam.

Até agora, estudamos conceitos como cliente, servidor, endereço IP, porta e banco de dados. Nesta atividade, vamos colocar parte desses conhecimentos em prática.

Nosso desafio será criar um site em um computador e permitir que outros computadores o acessem pela rede Wi-Fi de um celular.

Para isso, utilizaremos o VS Code para desenvolver o projeto, o Python com Flask para executar o servidor e o HTML para construir a página.

Também criaremos um mural de mensagens. Assim, diferentes computadores poderão enviar informações para um mesmo servidor.

Ao final, vocês perceberão que uma aplicação desenvolvida por vocês pode funcionar em outros dispositivos, sem precisar ser publicada na internet.

01Etapa 1 — Preparando nossa rede

Antes de começarmos a programação, precisamos conectar os computadores.

Um integrante do grupo deverá disponibilizar uma rede Wi-Fi utilizando a função de roteador do celular.

No celular:

  1. Acesse as configurações.
  2. Procure Roteador Wi-Fi, Ponto de acesso ou Hotspot.
  3. Ative a função e configure uma senha.
  4. Conecte os computadores do grupo à mesma rede Wi-Fi.

Não é necessário utilizar os dados móveis para a comunicação local. O importante é que os computadores estejam conectados à mesma rede e que o celular permita a comunicação entre eles.

Como será nossa organização?

  • O celular cria a rede Wi-Fi.
  • Um computador será escolhido como servidor.
  • Os outros computadores serão os clientes.
  • Todos acessarão o mesmo site.

02Etapa 2 — Criando o projeto no VS Code

No computador escolhido como servidor, vamos organizar nossos arquivos.

  1. Abra o VS Code.
  2. Crie uma pasta chamada rede-flask.
  3. No VS Code, escolha Arquivo → Abrir Pasta.
  4. Abra a pasta que acabamos de criar.

Dentro dela, crie um arquivo chamado:

app.py

Em seguida, crie uma pasta chamada:

templates

Dentro da pasta templates, crie:

index.html

Nossa organização ficará assim:

TEXT
rede-flask/
│
├── app.py
│
└── templates/
    └── index.html

Por que precisamos desses arquivos?

O app.py será responsável pela programação do servidor. Já o index.html será responsável pela página exibida no navegador.

03Etapa 3 — Instalando o Flask

O Flask é uma ferramenta do Python que permite desenvolver aplicações web.

Com ele, podemos transformar nosso programa em um servidor capaz de receber solicitações de outros computadores.

No VS Code:

  1. Clique em Terminal → Novo Terminal.
  2. Digite o comando:
POWERSHELL
py -m pip install flask
  1. Pressione Enter e aguarde a instalação.

Caso o comando py não funcione, tentem utilizar python no lugar dele.

Atenção: para instalar o Flask, o computador poderá precisar de acesso à internet. Se já estiver instalado, não será necessário instalar novamente.

04Etapa 4 — Programando o servidor

Agora vamos escrever o código responsável pelo funcionamento do nosso site.

Abra o arquivo app.py e insira:

PYTHON
from flask import Flask, render_template, request, redirect, url_for

app = Flask(__name__)

mensagens = []

@app.route("/", methods=["GET", "POST"])
def inicio():

    if request.method == "POST":
        nome = request.form.get("nome", "").strip()[:30]
        texto = request.form.get("mensagem", "").strip()[:200]

        if nome and texto:
            mensagens.append({
                "nome": nome,
                "texto": texto
            })

        return redirect(url_for("inicio"))

    return render_template(
        "index.html",
        mensagens=mensagens
    )

if __name__ == "__main__":
    app.run(
        host="0.0.0.0",
        port=5000,
        debug=False
    )

Salve o arquivo com Ctrl + S.

Vamos compreender o que programamos?

O Flask cria uma aplicação web. Quando alguém acessa o endereço do servidor, o Python envia a página HTML.

Quando uma pessoa preenche o formulário, o Python recebe os dados e adiciona uma mensagem à lista.

A informação passa a estar disponível para os demais computadores que acessam o site.

Observem especialmente:

host="0.0.0.0"

Essa configuração permite ao Flask receber conexões pela rede, e não somente do próprio computador.

Já port=5000 indica a porta utilizada pela aplicação.

06Etapa 6 — Ligando nosso servidor

Voltaremos ao terminal do VS Code.

Certifiquem-se de que estão na pasta rede-flask e executem:

POWERSHELL
py app.py

Se o comando funcionar, o terminal apresentará uma mensagem semelhante a:

TEXT
Running on http://127.0.0.1:5000

Isso significa que nosso servidor começou a funcionar.

Para testar, abram o navegador do próprio computador servidor e acessem:

http://127.0.0.1:5000

A página deverá aparecer.

Importante: não fechem o terminal enquanto estiverem utilizando o servidor.

07Etapa 7 — Descobrindo o IP do computador

Nosso site já funciona, mas ainda precisamos permitir que os outros computadores o encontrem.

Como fazemos isso?

Cada computador conectado à rede recebe um endereço IP.

Esse endereço permite identificar o dispositivo durante a comunicação.

No computador servidor:

  1. Abra outro terminal no VS Code, sem fechar o terminal que executa o Flask.
  2. Digite:
POWERSHELL
ipconfig
  1. Procure o endereço IPv4 da conexão Wi-Fi.

Exemplo:

192.168.43.101

Esse número é apenas um exemplo. Vocês deverão utilizar o IP encontrado no próprio computador.

Anotem esse endereço, pois ele será utilizado pelos colegas.

08Etapa 8 — Acessando o site em outro computador

Chegamos ao principal desafio!

No segundo computador, conectado ao mesmo Wi-Fi do celular:

  1. Abra um navegador.
  2. Digite o endereço IP do servidor.
  3. Acrescente :5000 ao final.

Exemplo:

http://192.168.43.101:5000

Pressione Enter.

Se a comunicação estiver funcionando, o site aparecerá no navegador do segundo computador.

Isso significa que conseguimos estabelecer uma comunicação entre computadores utilizando a rede local!

Caso a página não abra, verifiquem se os dispositivos estão no mesmo Wi-Fi, se o IP está correto e se o servidor continua funcionando. O firewall ou as configurações do roteador também podem impedir a conexão; nesse caso, solicitem orientação ao professor.

09Etapa 9 — Testando nosso mural coletivo

Agora vamos verificar como funciona uma aplicação compartilhada.

Realizem o seguinte experimento:

  1. No computador 1, abram o site e enviem uma mensagem.
  2. No computador 2, abram a mesma página.
  3. Verifiquem se a mensagem está aparecendo.
  4. Enviem outra mensagem pelo computador 2.
  5. Atualizem a página do computador 1 utilizando F5.

Observem o resultado.

Os computadores estão acessando uma mesma aplicação, executada em um único servidor.

Percebam a importância dessa experiência: os clientes não precisam ter o código Python instalado. Eles acessam a aplicação pelo navegador, enquanto o servidor executa a programação.

As mensagens ficam armazenadas temporariamente na memória do programa. Quando o servidor for reiniciado, elas serão apagadas. Em uma próxima etapa, poderemos utilizar o SQLite para armazená-las permanentemente.
